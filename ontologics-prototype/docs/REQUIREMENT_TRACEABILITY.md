# 요구사항과 화면 추적표

요구사항 근거는 첨부 정의서입니다. 장 번호를 사용하며 Word 렌더링의 페이지 번호와 혼동하지 않습니다. 모든 상태는 프론트엔드 범위입니다. “시연”은 실제 서비스 수용 완료가 아닙니다.

| UX01 | 업무 목적을 읽을 수 있는 화면 | 공통 | 공통 헤더·내비·상태·입력 보존·라벨·Radix 모달. 서버 권한은 미연동 | AT07 | 시연 |
| UX02 | 현황에서 재개 | UI01, 공통 | 현황에서 대상 화면 재개·초안 버전 조회. 실제 권한 회수/삭제 연동 없음 | AT07 | 시연 |
| UX03 | 업무별 안내 | UI01, 공통 | 목적별 세 흐름·빈 상태/오류·선행 자료 안내 | AT07 | 시연 |

## 수용 테스트 연결

| 수용 ID | 실행한 검사 | 수용에서 남은 부분 |
|---|---|---|
| AT01 | 브라우저 원본→초안→승인→반영→재조회; 매핑 검증 | 범용 파싱·PDF 전체 대조·실제 서버 |
| AT02 | 브라우저 보완/전후 비교; A/B 경계 단위 검사 | 실제 DB/운영 기록 |
| AT03 | 자기 승인·Viewer·해시 변조·구기준·멱등 키 검사 | 서버 신원·트랜잭션·동시성 |
| AT04 | 브라우저 수요/예약/입고/합격할당/조건부 일정; 상한 검사 | 실제 일정 계산·현장 API |
| AT05 | 브라우저 100/60/50/20/15/20 → 40/10/15/20/15/80; 시간·수량 실패 검사 | 임의 회차·예측·입고 시각·서버 연동 |
| AT06 | 브라우저 보드 식별·의뢰·가상 시험·구성별 예시 | D02/D03/D06·실제 시험 충돌/중복 집계 |
| AT07 | 직접/AI 공통 계산·장애 시연·입력 보존·모바일·키보드 | 실제 모델/검색/Host·담당자 사용성 평가 |
| AT08 | 미실행, 화면에 미연동 명시 | PostgreSQL/RDF/Neo4j 동일 조건 조회·동기화 실패 |
