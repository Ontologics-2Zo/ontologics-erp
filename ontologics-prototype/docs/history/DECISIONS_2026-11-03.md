# 공통 계약 미결 사항

정의서 21장의 D01~D07은 모두 미결입니다. 추천안을 제품 정책 확정으로 바꾸지 않았습니다.

| ID | 주제 | UI 처리 | 남은 결정 |
|---|---|---|---|
| D01 | 역할 인계 | 대상·근거·버전·미확정을 검토 후보로 유지. 자동 송부·접수 없음 | 인계 응답·멱등·오래된 버전 계약 |
| D02 | 생산 작업 참조 | 가짜 작업 ID와 라인 목록을 만들지 않음 | 계획/실적 작업의 안정 ID·참조 버전 |
| D03 | 보드 소속 | 납품 집계량을 보드 목록으로 변환하지 않음 | 회사·구성·위치·유효시점·목록 완전성 |
| D04 | 부분 생산 전이 | 근거 있는 입고 후 사용자 명시 배정으로 시연. 임의 FIFO 없음 | 실제 중복 방지와 회차 배정 공통 계약 |
| D05 | 부분 인수 | 한 출하 전량 도착만 시연. 부분 수량 입력 시 미결 이유로 차단 | 채택 여부 및 출하별 여러 도착·미인수 |
| D06 | 시험·재생산 | 시험팀 가상 자료와 독립 수량 예시. 미검사·미결·범위 유지 | 자료 허용 범위·판정·집계·재생산 계약 |
| D07 | 운영 수용값 | 운영 인증·성능·보관·복구·한도 미완료 명시 | 운영 책임자의 값과 환경 확정 |

부분 생산과 부분·분할 출하 자체는 필수 범위입니다. D04와 D05를 이유로 해당 기능을 전량 처리로 축소하지 않았습니다. 분할 출하 20/15대는 지원하며, 한 출하의 일부만 도착하는 부분 인수와 구별합니다.
